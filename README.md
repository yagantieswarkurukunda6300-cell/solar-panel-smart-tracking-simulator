## 🌞 SMART SOLAR TRACKING SIMULATION

### ☀️ Follow the Sun. Rotate the Panel. Maximize the Power.

The **Solar Panel Smart Tracking Simulator** is an interactive web-based Electrical Engineering project developed using **React and Vite**.

It digitally simulates how a solar panel can change its orientation according to the changing position of sunlight.

The simulator calculates the required tracking angle, rotates a virtual solar panel, estimates power generation, compares tracking performance with a fixed panel, and visualizes the results through an interactive dashboard.

## 🧠 CORE LOGIC

The simulator converts the Sun's position into a corresponding panel orientation.

### 📐 Tracking Angle

```text
Tracking Angle = (Sun Position - 50) × 1.2
```

The calculated angle controls the virtual solar panel rotation.

### ⚡ Power Estimation

```text
Power = 100 × cos(|Tracking Angle|)
```

The estimated power output changes according to the panel's alignment with the sunlight.

## ⚖️ TRACKING PANEL vs FIXED PANEL

| System            | Working Principle                         |
| ----------------- | ----------------------------------------- |
| 🔄 Tracking Panel | Changes orientation according to sunlight |
| 📌 Fixed Panel    | Maintains a constant orientation          |

The comparison demonstrates the importance of proper solar panel alignment.
